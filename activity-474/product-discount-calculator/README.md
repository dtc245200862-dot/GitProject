# CodeGym Activity 474

Product Discount Calculator using JSP and Servlet.

- `index.jsp`: nhập mô tả sản phẩm, giá niêm yết và tỷ lệ chiết khấu.
- `DiscountServlet`: nhận dữ liệu bằng POST, tính Discount Amount và Discount Price.
- URL xử lý: `/display-discount`.

Công thức:
`Discount Amount = List Price * Discount Percent * 0.01`
`Discount Price = List Price - Discount Amount`
