01 / WEB DEVELOPMENT

Web Technology

HTML là ngôn ngữ đánh dấu siêu văn bản được sử dụng để xây dựng cấu trúc của trang web. CSS giúp định dạng, thiết kế và tạo giao diện hấp dẫn cho trang web.

Khi kết hợp HTML và CSS, chúng ta có thể tạo ra những trang web có bố cục rõ ràng, màu sắc đẹp và hiển thị phù hợp trên nhiều thiết bị.

Tìm hiểu HTML và CSS
<HTML> { CSS }
02 / PROGRAMMING

C Programming

C là ngôn ngữ lập trình thủ tục được sử dụng rộng rãi trong lập trình hệ thống, phát triển phần mềm và học các kiến thức cơ bản về lập trình.

Khi học C, người học có thể làm quen với biến, điều kiện, vòng lặp, hàm, mảng và con trỏ.

Khám phá lập trình C
#include <stdio.h> int main() { }
03 / OBJECT-ORIENTED PROGRAMMING

Java Programming

Java là ngôn ngữ lập trình hướng đối tượng được sử dụng trong nhiều lĩnh vực như ứng dụng desktop, web và phát triển phần mềm.

Người học Java có thể tìm hiểu lớp, đối tượng, tính kế thừa, tính đóng gói và tính đa hình.

Học lập trình Java
public class Main System.out.println();
