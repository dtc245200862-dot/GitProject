# CodeGym Activity 487

JSP Pure Dictionary - ứng dụng tra cứu từ Anh – Việt bằng JSP.

- `index.jsp`: form nhập từ tiếng Anh và gửi bằng POST.
- `dictionary.jsp`: dùng JSP Scriptlet và Expression để tra cứu từ trong Map.
- `WEB-INF/web.xml`: cấu hình Jakarta Servlet API cho Tomcat 10+.
- `pom.xml`: Maven Webapp, Java 17, packaging WAR.
