# Activity 471 - JSP Servlet Login

Du an Maven Webapp Java JSP/Servlet tuong thich Tomcat 10.1+.

## Chuc nang
- Hien thi form dang nhap tai index.jsp.
- Gui username va password bang POST toi /login.
- Tai khoan dung: admin / admin.
- Dang nhap dung hien thi: Welcome admin to website.
- Dang nhap sai hien thi: Login Error.

## Cau truc
- pom.xml
- src/main/java/com/codegym/LoginServlet.java
- src/main/webapp/index.jsp
- src/main/webapp/WEB-INF/web.xml

## Chay du an
mvn clean package

File WAR duoc tao tai target/jsp-servlet-login.war.
