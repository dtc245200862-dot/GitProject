# Activity 488 - Luyện tập sử dụng JSTL trong JSP

Bài thực hành hiển thị danh sách khách hàng bằng JSP và JSTL.

## Nội dung
- Tạo danh sách khách hàng gồm tên, ngày sinh, địa chỉ và ảnh.
- Khai báo JSTL Core bằng taglib.
- Sử dụng `<c:forEach>` để duyệt danh sách và hiển thị dữ liệu.
- Thư viện JSTL được khai báo trong `pom.xml`.

## Chạy bài
Dùng Maven để build file WAR và triển khai lên Tomcat/Servlet container hỗ trợ JSP và JSTL.
